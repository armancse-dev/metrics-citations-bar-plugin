# Metrics and Citations (ACF)

A WordPress plugin that adds a **Metrics and Citations drawer** to posts and pages.  
It uses **Advanced Custom Fields Pro (ACF Pro)** repeaters to store and display citation formats and export links, and also tracks views & downloads automatically.

---

## Features

- 📊 **Track Post Views** – counts and displays total views per post.
- ⬇️ **Track Downloads** – automatically counts attachment downloads.
- 📑 **Metrics Drawer** – adds a collapsible drawer with:
  - Journal name
  - DOI & Altmetric widget
  - Publication usage (views & downloads)
  - Citations (ACF repeater)
  - Export links (ACF repeater)
- 📝 **Default Citations** – new posts/pages start with 4 default citation rows:
  - APA
  - MLA
  - Chicago
  - Harvard
- 🎨 **Custom Styling** – plugin includes CSS and JS for the drawer UI.

---

## Requirements

- WordPress 5.0+
- [ACF Pro](https://www.advancedcustomfields.com/pro/) (for repeater fields)
